A little app that finds every font on your computer and turns the whole collection into a browsable, sortable type specimen book, without moving, copying, or touching a single file. Type any headline and see it in everything you own.

What it does

  • Scans your font folders (or your whole home folder) and indexes every TTF, OTF, TTC, WOFF and dfont in place.
  • Sorts fonts into style categories (Serif, Sans, Slab, Mono, Script, Blackletter, Display) using each font's internal style data. Fully offline.
  • AI mode (optional): bring your own Anthropic API key and Claude sorts by what it knows of each typeface, takes a wish list of categories (Art Deco, Y2K, Good for Posters…), and can file a font under several. Only font names are ever sent, never files.
  • Test headlines in every font at once, in one to three columns, click or drag to shortlist favorites, and re-file anything with one click.
  • Export a real PDF specimen sheet of your selection: page size, columns, font size, and file paths all configurable.

Get it

download font atlas   view the code

  1. Unzip it anywhere.
  2. Mac: right-click Start Font Atlas.command and choose Open (only the first time).
    Windows / Linux: run python3 app.py in the folder.
  3. It opens at localhost:8765. Hit scan. That's it.

No installs, no dependencies beyond Python 3 (Macs have it), no accounts. Everything runs locally and nothing leaves your computer, unless you switch on AI mode with your own key, and even then only font names travel. Your fonts stay exactly where they are.
