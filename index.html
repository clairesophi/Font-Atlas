    Sort fonts

    How should fonts be sorted into categories? Either way, fonts you sorted by hand (✓) are never touched.

    Built-in Instant and fully offline. Reads each font's internal style data and name. Re-applies the automatic suggestions to everything you haven't sorted by hand.
    AI (Claude) Uses your own Anthropic API key. Knows typefaces by reputation, files each font into exactly one category, and applies your wish list of tags where they genuinely fit.

    AI sorting mode

    Claude files every font into exactly one of your style categories (Serif, Sans, Mono…) and applies tags on top: any number per font, only where they genuinely fit. Only font names are sent, never the font files.

    A tag only goes on fonts that genuinely fit it, so a font can be Serif and tagged Art Deco, while most fonts carry no tags at all. Claude may also invent a few tags of its own when it spots a group worth naming. Leave the box empty to just sort into the sidebar categories.

    Get a key at console.anthropic.com/settings/keys (sign in, then “Create Key” and copy the sk-ant-… value). If sorting stops with a “workspace-id is required” error, copy your workspace's ID from console.anthropic.com/settings/workspaces into the field above and run it again. The key is saved in plain text in this app's local data folder on this computer and is only ever sent to api.anthropic.com. Sorting ~1000 fonts costs roughly a dollar. Hand-sorted fonts are never overwritten.
